# Project: Health System Application

## Overview

This project creates a Maui App for a health system program where you can add patients, physicians and appointments.

### What it does:

- Adding patients to the system, name, address, birth date, race, gender, and able to delete or edit any of these options.
- Adding physicians to the system, name, License number, graduation date, and specialization, able to delete or edit any of these options
- To create or update appointments between patient and physicians.
